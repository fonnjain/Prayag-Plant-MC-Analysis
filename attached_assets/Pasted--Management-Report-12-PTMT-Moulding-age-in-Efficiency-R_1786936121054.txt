## Layout — per-mould rows, month blocks across

**Fixed left columns**, repeated once:

```
S.NO. | MOULD | TYPE | NAME | CAVITY | CYCLE TIME PER PC | PC WEIGHT
```

**Then repeating four-column blocks**, `TOTAL` first, then each month:

```
Production in Pcs | M/C Run Minute (Ideal) | M/C Run Minute (Actual) | Efficiency in %age
```

One row per **mould** — roughly 393 of them, not per machine. A `TOTAL` row sits above the mould rows.

---

## Both formulas are confirmed — derive, do not copy

Verified against four independent rows, exact in every case:

```
Ideal M/C Run Minute  =  Production in Pcs  ×  CYCLE TIME PER PC  ÷  60

  PSF-219   1,404,770 × 6.25   ÷ 60 = 146,330    sheet 146,330
  PSF-23      314,711 × 21.25  ÷ 60 = 111,460    sheet 111,460
  PSF-314      65,460 × 100.00 ÷ 60 = 109,100    sheet 109,100
  PSF-184     747,531 × 8.75   ÷ 60 = 109,015    sheet 109,015
```

**`CAVITY` is not in the formula** — cycle time is already per piece. It is informational; do not multiply or divide by it.

```
Efficiency in %age  =  Ideal Minutes  ÷  Actual Minutes

  TOTAL     4,437,919 ÷ 4,414,618 = 100.53%
  Apr'26      891,279 ÷   918,451 =  97.04%
  May'26      952,311 ÷   936,751 = 101.66%
  PSF-184     109,015 ÷   109,511 =  99.55%
```

Note the direction: **ideal over actual**, so a mould running faster than its standard exceeds 100%. Values above 100% are valid and common in this sheet — 119.55%, 142.68%, 173.13% all appear. **Do not cap them.**
