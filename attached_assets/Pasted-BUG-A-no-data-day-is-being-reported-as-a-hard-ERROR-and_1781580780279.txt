ROOT-CAUSE RULES TO IMPLEMENT

1) Classify the "nothing to publish" roll-up by WHY the period is empty,

     treatment.
   - Only if the period is fully in the PAST and CLOSED and still has no

   periods. Show them as "—" / "Not available yet" with the INFO note.

   stays as-is.

3) "No data could be published" must never be counted as an independent
   error when it is purely the consequence of completeness/reconciliation

   status line, not a counted error.

   card, PDF). Define one counting function and reuse it everywhere. Decide

5) Fix the completeness card showing "0/0 machines" — for a no-data period
   show the roster count with 0 reporting (e.g. "0/<roster>"), or "n/a for
   this period", never "0/0".
