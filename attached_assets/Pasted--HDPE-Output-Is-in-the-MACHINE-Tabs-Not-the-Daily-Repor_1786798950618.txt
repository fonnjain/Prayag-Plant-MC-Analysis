## The defect

QA reports HDPE July missing from both Machine View and Plant View. **They are right, and the cause is structural.**

Verified by direct read of the July daily workbook (`1M4oXFOmKelpCYpGDatjReTF5scJwcg8saFVPcRRORtA`, "4. HDPE Date Sheet & Monthly Report - July ' 2026"):

| Tab | Rows | Output |
|---|---:|---:|
| `MACHINE NO : 001` | 41 | **21,931.28 kg** (the sheet's own summary cell reads 21,931; rejection 3,782) |
| `MACHINE NO : 002` | 7 | **516.76 kg** |
| `MACHINE NO : 003`–`006` | 0 | present but entirely empty |
| **Total** | **48** | **22,448.04 kg** |

The tab the application reads — **`Daily Report`** — is **entirely zero**: TOTAL row 0 run hours / 0.00 output / 0.00 rejection, every machine row blank, plus a `DANA MC` / `SHEADER` / `GRINDER` block also at zero.

**This is the Garden pattern.** Real production is entered in per-machine block tabs; the app reads a Daily Report matrix that is not being maintained. `_DAILY_LAYOUTS["HDPE"]` points only at the matrix.

### A correction that matters for scope

An earlier analysis of mine concluded HDPE "barely ran all year — only May, M/C-1, 1,370 kg." **That was drawn from the annual summary**, which is itself fed from the same empty Daily Report. It is therefore unsafe. **April, May and June must be re-checked against their MACHINE tabs**, not assumed idle.
