# Dashboard Metrics — Read Utilisation & Output Efficiency from the Monthly Masters

**Context:** A QA review flagged Output Efficiency, M/C Efficiency, Utilisation and Rejection as blank across most segments. A read-only diagnostic concluded these were "null by invariant — no baseline configured." **That conclusion was only partly right.** I have now read all six FY26-27 monthly master workbooks cell-by-cell for Apr–Jul 2026. Three segments **already carry an Ideal-Output column and compute Output Efficiency in the sheet**, and four carry **complete per-machine × month utilisation**. The app is suppressing values the source actually has.

**Root cause:** the model encoded in `baselines.json`'s comment is stale. It says GARDEN/TANK are "output-only" and PIPE/MOULDING have "no shift-pattern data." That is no longer true of the source sheets.
