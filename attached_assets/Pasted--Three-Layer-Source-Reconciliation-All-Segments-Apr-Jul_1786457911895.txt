**Purpose:** Every segment's FY26-27 data exists in up to three layers, and they do not agree. Before deciding which layer is authoritative, produce a complete reconciliation grid showing, for every segment × month, what each layer holds and exactly where data is missing.

**This pass decides nothing. It only measures.**

## HARD CONSTRAINTS

- **Do NOT edit any file.** No `.py`, no templates, no `sources.py`, no `baselines.json`.
- **Do NOT enter Build mode.** No restart, redeploy, or publish.

## The three layers

| Layer | What it is | Typically carries |
|---|---|---|
| **A — Detail / block tabs** | item-level entry rows (per date, per item code, per machine) | output only |
| **B — Daily Report matrix** | per machine × date matrix | run hours, output, **rejection** |
| **C — Annual summary** | monthly roll-up in the FY workbook | all, derived |

Layer names differ per segment — locate each by inspecting the workbook, not by assuming a tab name. Parse **by header text**, never by fixed column position. Map months **by label**.

## Segments and months to cover

**Months:** APR, MAY, JUN, JUL 2026 (all four, every segment).

**Segments:** GARDEN, PIPE, HDPE, MOULDING, PTMT, TANK (KH, VN, WB separately).

For segments where a layer does not exist at all (e.g. Tank has no machine/hours dimension; PTMT's daily source is Report-5), record it as **layer absent by design** — that is a finding, not a failure.

## For every segment × month, report

1. **Layer A total** — output kg (or Ltr for Tank). State the tab(s) summed and the row count.
2. **Layer B total** — run hours, output, rejection, and the sheet's own rejection %. State the tab.
3. **Layer C total** — output, rejection, hours as the annual roll-up shows them.
4. **Gaps:** A−B, B−C, A−C, each in absolute units and %.
5. **Per-machine breakdown for A and B** where a machine dimension exists, so partial entry is visible (e.g. a machine present in A but zero in B).
6. **Classification** — exactly one of:
   - `ALL AGREE` — the three layers reconcile within 0.5%
   - `B INCOMPLETE` — Layer B is missing machines/dates that Layer A records
   - `A INCOMPLETE` — Layer A is missing what B records
   - `C STALE` — C does not match B (which normally feeds it)
   - `LAYER ABSENT` — a layer does not exist for this segment (state which, and whether by design)
   - `SYSTEMATIC GAP` — all layers populated but a consistent non-zero difference remains
7. **Where a gap exists, characterise it:** is it concentrated in specific machines or dates, or spread evenly? Are there item categories present in A but seemingly excluded from B (e.g. WASTE PIPE, CONNECTION, braided items)?
