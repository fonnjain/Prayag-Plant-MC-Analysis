Add an in-app **Glossary & metric help** to the existing Prayag Production Analytics dashboard, mobile-first, so users can see what every term means and how it's calculated without leaving the app. Two parts:

## 1) Tappable info tooltips on every metric label
Wherever a metric label appears (the machine card's A / P / Q / OEE / Att., the KPI cards, and report column headers), add a small **(i)** info affordance. Tapping it opens a lightweight popover/bottom-sheet (mobile-friendly, dismiss on tap-away) showing the term's short definition, its formula, and its unit. Keep it to 1–3 lines. Examples:
- **OEE** — Overall Equipment Effectiveness. How effectively a machine runs vs ideal. Formula: A × P × Q. Unit: %.
- **A — Availability** — Share of planned time the machine was actually running. A = Run Time ÷ Planned Production Time. %.
- **P — Performance** — Actual speed vs ideal speed. P = Total ÷ ((Run Time ÷ 60) × Ideal rate). %.
- **Q — Quality** — Share of output that was good. Q = Good ÷ Total. %.
- **Att. — Attainment** — Actual output vs planned/target. Att. = Actual ÷ Planned. %.
- **DT — Downtime** — Minutes stopped during planned time. Unit: minutes.
- **units — Output** — Total quantity produced (pcs / kg / ltr).

## 2) A full "Glossary" screen
Add a **Glossary** entry reachable from the app (a "?" / help icon in the top header, and/or an item under a "More" tab). It's a mobile-first scrollable page with three sections, using the app's styling (navy #1F3864, terracotta #C55A11 accents, green/amber/red rating colours), cards/tables that scroll horizontally if needed.

**Section A — Glossary** (term · meaning · unit · where used):
OEE = Overall Equipment Effectiveness (A×P×Q), %, all OEE views.
A = Availability — planned time actually running; %, machine card.
P = Performance — actual vs ideal speed; %, machine card.
Q = Quality — good ÷ total; %, machine card.
Att. = Attainment — actual ÷ planned output; %, machine/plant.
DT = Downtime — minutes stopped in planned time; minutes; losses.
units = Output — total produced; pcs/kg/ltr; everywhere.
PPT = Planned Production Time — shift length − planned stops; minutes.
Run Time = PPT − downtime; minutes.
Good = Total − Reject; pcs/kg.
Ideal rate = standard output per hour; units/hr.
Reject % = Reject ÷ Total; %.
Runner % = runner produce ÷ total; kg/%; moulding & PTMT.
Lumps = start-up/purge waste; kg; PTMT.
Utilisation = actual hours ÷ ideal hours; %; machine/mould.
Output efficiency = actual vs ideal output (or run-hours); %.
Mould age-in-efficiency = efficiency % tracked vs mould age; %.
Weight-loss % = (material in − out) ÷ material in; %; compound.
Labour cost/kg = wages ÷ output; ₹/kg. Cost/hour = wages ÷ paid hours; ₹/hr.
FY = Financial Year (Apr–Mar). YoY = year-on-year vs prior FY.
Plant/Unit = KH, VN, WB or Unit-1/2/3. Segment = CP, PTMT, Sink, Hinges, Pipe & Fitting, Garden, HDPE, Tank.
M/C = machine. Mould = tool with cavity/cycle/pc-weight.
Machine code = type-plant+number, e.g. TK-VN1 = Tank line, VN plant, machine 1.
