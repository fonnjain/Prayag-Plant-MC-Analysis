0. The one non-negotiable rule

Every number in every Management Report is RECOMPUTED from the daily source workbooks. Nothing is ever copied from a final/summary sheet.


Stored % cells, stored totals, and pre-rolled summary tabs are never trusted — recompute them.
The final report sheets (the "(A)…(D)", Garden, HDPE, %age, Tank, PTMT, Compound, Segment-Cost workbooks) are used for two things only: (a) to mirror the output format/column order/labels, and (b) to validate the recomputed numbers. Their values never flow into the report.
Claude/AI writes narrative text only — never a single number. All figures come from deterministic Python that reads source cells.
Parse by header text, not fixed column index — source layouts drift between months and fiscal years.
Be honest about gaps: if a source month is empty or a layout can't be verified, flag it "awaiting source / unverified" and do not publish a fabricated number.

2. Source column mappings (match by HEADER TEXT — indices below are hints, verify each run)

Report-11 (pipe daily; item × machine × type): header row 5. Machine = "MACHINE NO." (e.g. PIPE M/C - 1). Type = the first "TYPES" column (ignore the duplicate ~col22). Pcs = "Pcs" (~col9). Production weight = the standalone "Weight" col (~col10) — NOT "Ideal Weight". Rejection = "Actual Wt (Kg)" (~col14). Running hours ~col7. Aggregate to (machine, date).

Report-5 (pipe + moulding summary + daily): machine ~col3. Per-date detail starts ~col15 in 3-col groups [Run Hours, Output, Rejection]; the date sits in ROW 3 of each group's first column. Pipe machines rows ~5-13 (Pipe M/C-N); moulding machines below (codes like A02(U-150)) with output/rejection in their own group.

Report-12 (moulding daily): header row 4. FY26-27 → machine = "Moulding Machine" (~col5), output kg = "Wt in Kgs" (~col10), rejection = "Actual Rejection Weight" (~col26), hours = "Hour Consume for Production" (~col19). FY25-26 is shifted −1 (machine col4, output col9, rejection col25). Detect by locating the "Moulding Machine" header, then output = that column + 5.

Reports 17–20 (D — CPVC/UPVC/SWR/AGRI mould working): row-3 headers MOULD / MOULD CAVITY / CYCLE TIME PER PC / PC WEIGHT / RUNNER WEIGHT; then a production block PRODUCTION IN PCS / PRODUCTION IN KG / Weight of Total Production / MOULD UTILISATION IN HOURS. Each tab has a SINGLE production block = the workbook's current month. ⚠️ The block's row-2 month label can be stale (e.g. reads "APRIL'26" in the June workbook) — ignore the label; the data is the workbook's month. Confirm by the tie-out in §3.

Garden Pipe: tabs MACHINE 1-4, data from row 6. Production kg = "TOTAL" (~col8), pcs = "NOS" (~col5), mtr (~col6). No rejection column.

HDPE: tabs MACHINE 1-6 + DANA MC + "Total Production". Output kg ~col8, rejection ~col7. Empty months read all-zero → flag "awaiting source", don't treat as real zero.


3. Reconciliation rules (the analytical backbone — implement exactly)


Pipe (A) — date-wise max. Report-5 and Report-11 disagree and each is more complete in different months (R11 led Apr/May'26; R5 led June; R5 became unreliable from Mar'26 and drifts both directions — never use R5 alone). Rule: at (machine × date) grain take max(Report-5, Report-11) over the union of all machine-dates, then sum. Apply the same to rejection. This is the pipe headline for output and rejection.
Moulding (B/C/%age) — Report-12 is authoritative. Report-5's moulding block equals Report-12 to the kg every month; use Report-12.
Type split (CPVC/UPVC/SWR/AGRI) exists ONLY in Report-11. Where the max rule picks a Report-5 machine-date (no type info), label that output "untyped pickup" and scale Report-11's type proportions pro-rata to each machine's corrected total. Report the typed % completeness.
(D) validation tie-out. Sum of Reports 17–20 (kg) must reconcile to the same workbook's Report-12 month total within ~0.1% (per-material splits differ by design — Report-12 tags by item material and carries small PP/PPR/ABS lines; mould reports tag by mould family). If the grand totals don't tie, the block isn't the current month — stop and flag.
Aug'25 (and any empty month): pipe side may be empty while moulding is real — flag "awaiting source", never roll a false zero into annual figures.
Layout drift: Report-12 shifts one column between FY25-26 and FY26-27; Report-11 has a duplicate TYPE column. Always resolve columns by header text.
Roster reconciliation: 9 pipe M/C (M/C-1..9), 26 moulding codes (A01-A06, B01-B06, C01-C07, D01-D07). Some machines appear in one report but not the other in some months (e.g. C03 in Report-5 but missing from Report-12 in ~3 months) — surface these as coverage warnings, don't silently drop.


Efficiency caveat: corrected output uses the date-wise max but run-hours stay on Report-5, so output ÷ hours can look inflated on some machines — flag it; hours may later get the same date-wise treatment.
