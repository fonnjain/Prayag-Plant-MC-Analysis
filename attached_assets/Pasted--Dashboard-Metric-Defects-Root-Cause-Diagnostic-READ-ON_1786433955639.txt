## Background the diagnostic must use (already in the code — do not change it)
- `api.py::_metrics_json` nulls a metric when its availability flag is false: `eff_available`→output_efficiency, `util_available`→utilisation, `oee_available`→oee/availability/performance/quality, `planned_output`→attainment, `total_count`→rejection_pct/runner_pct.
- `baselines.resolve(plant, machine, month)` returns the ideal/planned baseline from config; `ideal_output` is `None` when no `ideal_output_rate` is configured, and the whole result is `None` when neither a per-machine entry nor a per-plant `formula_defaults` exists. When config is absent the app keeps `ideal_source='sheet'` and uses the sheet's own ideal — if the sheet has none, efficiency/utilisation/attainment cannot be computed and correctly render blank.
